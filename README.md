# Publish this portfolio on GitHub Pages

This folder is already built. It contains the required `index.html` at the upload root, all assets, videos, images, resume PDF, and a `.nojekyll` file. **Do not edit the files, run a build command, or create a GitHub Actions workflow.**

## Publish in five steps

1. Create a new public GitHub repository named `jimmy-libot-portfolio`.
2. Open this folder, `jimmy-libot-portfolio-github-pages-static`.
3. Upload everything **inside this folder** to the GitHub repository root. You must see `index.html`, `assets/`, `media/`, and `.nojekyll` at the root of the repository. Do not upload the outer folder or the ZIP file.
4. In the repository, go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Select branch **main**, choose the **/(root)** folder, then click **Save**.
5. Wait about one to three minutes, then open the URL shown under Settings → Pages.

For the username `jhimmylibot1998-sys` and repository name `jimmy-libot-portfolio`, the address will be:

```text
https://jhimmylibot1998-sys.github.io/jimmy-libot-portfolio/
```
